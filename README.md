# game-kartu-putri-syifa-nabilah
Game sederhana untuk melatih data ingat dengan mencocokkan gambar
Game kartu memori adalah permainan berbasis web yang menampilkan 16 kartu 
dengan 8 pasangan gambar yang tersusun acak dalam grid 4x4, pemain harus buka 2 gambar 
untuk mencocokkan. Jika tidak cocok maka akan tertutup, permainan berakhir jika 8 pasangan 
di temukan 

# fitur
-16 kartu dengan 8 pasangan
-posisi kartu di acak secara random
-indikator jumlah pasangan yang sudah di temukan
-tombol ulang untuk mengulang permainan
-halaman khusus ketika menang, menampilkan total percobaan
-tampilan responsif

# teknologi yang di gunakan
-HTML
-CSS3
-JavaScrip
